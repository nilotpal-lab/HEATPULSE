# Phase 11: Data Ingestion Pipeline

**Date**: 2026-09-02
**Status**: Phase 11 — Pipeline Architecture

---

## Objective

Build a robust, reproducible data ingestion pipeline that transforms raw GIS and
demographic data into validated, application-ready GeoJSON and JSON assets.

---

## Pipeline Architecture

```
Raw Data Sources
  ├── data/raw/          ← Immutable source files (gitignored SHA256 checksums)
  ├── data/processed/    ← Validated/transformed data
  ├── data/runtime/      ← Application-used data (API responses, cached)
  └── data/validation/   ← QA reports and checksums

Scripts
  ├── scripts/validate-geometry.ts  ← GeoJSON validation
  ├── scripts/aggregate-ndvi.ts     ← NDVI aggregation at ward boundaries
  ├── scripts/census-ingest.ts      ← Census data ingestion
  └── scripts/cron-refresh.js       ← Scheduled thermal refresh (existing)
```

---

## Pipeline Stages

### Stage 1: Raw Data Acquisition
Download and store immutable source files with checksums.

```bash
# Example: Pune admin wards GeoJSON
curl -o data/raw/pune_wards/pune-admin-wards.geojson \
  "https://raw.githubusercontent.com/datameet/Pune_wards/main/admin_wards/pune-admin-wards.geojson"
sha256sum data/raw/pune_wards/pune-admin-wards.geojson >> data/raw/CHECKSUMS.md
```

### Stage 2: Validation
Run geometric validation on all ingested GeoJSON.

```bash
node scripts/validate-geometry.ts data/raw/pune_wards/pune-admin-wards.geojson
```

Checks performed:
- [x] Valid GeoJSON structure (FeatureCollection, valid geometry types)
- [x] All polygons are closed (first = last coordinate)
- [x] No self-intersections
- [x] CRS is EPSG:4326 (lat/lon)
- [x] All 15 wards present
- [x] Representative points within polygon bounds

### Stage 3: Transformation
Convert to application format and generate derived products.

```bash
# Generate representative points (centroids) for each ward
node scripts/generate-centroids.ts \
  --input data/raw/pune_wards/pune-admin-wards.geojson \
  --output data/processed/representative_points.geojson
```

### Stage 4: Distribution
Copy validated data to runtime directories for API use.

```bash
# Copy to public/ for client-side fetch
cp data/processed/pune-admin-wards.geojson public/data/

# Copy to data/runtime/ for API routes
cp data/processed/pune-admin-wards.geojson data/runtime/
```
